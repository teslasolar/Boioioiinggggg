α arch - Architecture

Component architecture management with scaffolding, wiring, and cleanup.

γ cache - Data Caching

High-performance caching with φ-weighted eviction policy.

γ1 hydrate γ2 query γ3 mutate γ4 evict 
// Hydrate cache with data
gamma.hydrate('tag:TT-001', { value: 25.5 }, { ttl: 60000, tags: ['temperature'] });

// Query cached data
const value = gamma.query('tag:TT-001');

// Mutate cached entry
gamma.mutate('tag:TT-001', v => ({ ...v, value: 26.0 }));

// Evict by tags
gamma.evictByTags(['temperature']);

Eviction Policies

lru  - Least Recently Used
lfu  - Least Frequently Used
fifo - First In First Out
ttl  - Time To Live
phi  - φ-weighted (balances recency + frequency using κ*)

System configuration, initialization, monitoring, and shutdown.

await delta.config_({ environment: 'production', kappa: 0.618 });

// Initialize

delta.onMonitor(metrics => console.log(metrics));

// Health checks

  { name: 'database', check: () => db.ping() },
  { name: 'cache', check: () => cache.isHealthy() }
]);

// Graceful shutdown
await delta.stop(30000);

θ sync - Synchronization

Diff, push, pull, and conflict resolution for distributed sync.

θ1 diff θ2 push θ3 pull θ4 resolve 
// Compute diff
const diff = theta.diff(oldState, newState);
// { changes: [...], added: 2, modified: 1, deleted: 0 }

// Push changes to remote
await theta.push(diff.changes, 'plc-target');

// Pull changes from source
const pulled = await theta.pull('cloud-source', { sinceVersion: 5 });

// Merge with conflict resolution
const merged = theta.merge(base, local, remote, 'newest');
// { merged: {...}, conflicts: [], applied: [...] }

Resolution Strategies

local   - Always use local value
remote  - Always use remote value
newest  - Use most recent value
merge   - Attempt to merge objects
manual  - Leave as conflict for manual resolution
