Kappa (κ) Balance

The chaos/order balance parameter that governs system behavior.

κ* = 1/φ ≈ 0.618
0 (Order) κ* (Optimal) 1 (Chaos)

62% chaos + 38% order = Optimal balance

κ ∈ [0,1]
  - 0   = Pure order (crystalline, rigid, predictable)
  - 1   = Pure chaos (entropic, random, unpredictable)
  - κ*  = 1/φ ≈ 0.618 = Golden ratio optimal

// Evaluate kappa state
omega.getKappa()
// { value: 0.618, label: 'optimal' }

// Adjust kappa
omega.setKappa(0.7)  // More chaotic
omega.resetKappa()   // Back to κ*

Agent & Task System

Output flow: Ω→agents→tasks→output

Agents

interface Agent {
  id: string;
  name: string;
  execute: (task: Task) => Promise<Result<unknown>>;
}

// Register an agent
omega.registerAgent({
  id: 'data-processor',
  name: 'Data Processor',
  execute: async (task) => {
    // Process the task
    return success({ processed: task.input });
  }
});

Tasks

interface Task {
  id: string;
  name: string;
  agent: string;      // Agent ID to execute this task
  input: unknown;
  priority?: number;  // Higher = more important
  timeout?: number;   // Milliseconds
}

// Submit a task
const result = await omega.submitTask({
  id: 'task-001',
  name: 'Process Data',
  agent: 'data-processor',
  input: { data: [1, 2, 3] },
  priority: 10
});

// Queue tasks for batch processing
omega.queueTask(task1);
omega.queueTask(task2);
const results = await omega.processQueue();

Output

interface OmegaOutput<T> {
  source: 'Ω';
  agent: string;
  task: string;
  output: T;
  timestamp: number;
}

Subsystem Access

All subsystems are accessible via Greek letter properties:

const omega = createOmega();
await omega.boot();

// Access subsystems directly
omega.α  // AlphaSubsystem (arch)
omega.β  // BetaSubsystem (build)
omega.γ  // GammaSubsystem (cache)
omega.δ  // DeltaSubsystem (sys)
omega.ε  // EpsilonSubsystem (api)
omega.ζ  // ZetaSubsystem (test)
omega.η  // EtaSubsystem (doc)
omega.θ  // ThetaSubsystem (sync)

// Example: Use cache subsystem
omega.γ.hydrate('key', { value: 42 });
const cached = omega.γ.query('key');

// Example: Use API subsystem
omega.ε.getRouter().get('/health', () => respond({ ok: true }));

Usage Examples

Quick Start

import { bootOmega } from '@konomi/engines';

// Boot with default configuration
const result = await bootOmega();
if (result.ok) {
  const omega = result.value;
  console.log('System ready:', omega.isReady());
}

Custom Configuration

import { createOmega } from '@konomi/engines';

const omega = createOmega();

await omega.boot({
  skipTests: false,
  config: {
    environment: 'production',
    kappa: 0.618,
    subsystems: {
      γ: { maxSize: 10000, policy: 'phi' },
      ε: { port: 8080 }
    }
  },
  onPhaseStart: (phase) => console.log(`Starting ${phase}...`),
  onPhaseComplete: (phase, success) => console.log(`${phase}: ${success ? '✓' : '✗'}`)
});
