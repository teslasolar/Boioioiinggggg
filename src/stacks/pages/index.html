Stack:Val

Value transformation pipeline for industrial data with quality and alarm support.

raw → typed → qual → ts → tag → alarm
StageTypeDescription
rawRawValuenumber | boolean | string | Buffer | null
typedTypedValueRaw value with type info and unit
qualQualifiedValueQuality: good | uncertain | bad | substituted | simulated
tsTimestampedValueTimestamp and source timestamp
tagTaggedValueTag metadata: id, name, area, unit
alarmAlarmValueAlarm state with severity levels

Alarm Limits

AlarmLimits {
  lowLow?:   number  // Urgent low (severity: urgent)
  low?:      number  // Low warning (severity: medium)
  high?:     number  // High warning (severity: high)
  highHigh?: number  // Urgent high (severity: urgent)
  deadband?: number  // Hysteresis for alarm clearing
}

Usage

import { createValStack, processValue } from '@konomi/stacks';

const tag = { id: 'TT-001', name: 'Tank Temperature' };
const limits = { low: 20, high: 80, highHigh: 95 };

const stack = createValStack(tag, limits);
const result = stack.process(85.5, { quality: 'good' });

// result.value.alarm = { active: true, severity: 'high', message: '...' }

Stack:Equip

ISA-88 (S88) and ISA-95 (S95) equipment hierarchy with PackML state machine.

CM → EM → Unit → Cell → Area → Site

ISA-95 Levels

LevelNameDescriptionTimescale
L0ProcessPhysical process (sensors, actuators)ms
L1ControlBasic control (PLCs, DCS)ms-s
L2SupervisorySCADA, HMIs-min
L3MOMManufacturing operations (MES)min-hr
L4BusinessBusiness planning (ERP)hr-day

ISA-88 Physical Model

TypeLevelDescription
CM (Control Module)L0-L1Single actuator, sensor, or control loop
EM (Equipment Module)L1Collection of CMs for a specific function
UnitL2Processing entity for material transformation
CellL2Collection of units working together

PackML States

Execute:  IDLE → STARTING → EXECUTE → COMPLETING → COMPLETE
Hold:     EXECUTE → HOLDING → HELD → UNHOLDING → EXECUTE
Suspend:  EXECUTE → SUSPENDING → SUSPENDED → UNSUSPENDING → EXECUTE
Stop:     * → STOPPING → STOPPED → RESETTING → IDLE
Abort:    * → ABORTING → ABORTED → CLEARING → STOPPED

State markers: ● (active) ○ (inactive)

Stack:Peer

P2P networking stack with CRDT support for distributed systems.

Key → Id → Addr → Info → Conn → Mesh
StageTypeDescription
KeyPeerKeyCryptographic key pair (Ed25519, secp256k1, RSA)
IdPeerIdDerived peer identifier (Base58 multihash)
AddrPeerAddrNetwork multiaddresses
InfoPeerInfoProtocols, latency, metadata
ConnPeerConnActive connection with streams
MeshPeerMeshNetwork topology with rooms

CRDT Types

CRDT:{reg, ctr, set, txt}

reg - LWW Register (Last-Writer-Wins)
ctr - PN-Counter (Positive-Negative)
set - OR-Set (Observed-Remove)
txt - Y-Text (Rich text with operations)

Room & Awareness

room → sync → aware

Room: Collaborative space for CRDT sync
  - id, name, topic
  - peers: Set of peer IDs

Awareness: Ephemeral presence state
  - user name, color, cursor position
  - lastUpdated timestamp

Usage

import { initPeerStack, createRegister, mergeRegisters } from '@konomi/stacks';

// Initialize P2P stack
const stackResult = await initPeerStack(['/ip4/0.0.0.0/tcp/4001']);
const stack = stackResult.value;

// Join a room
stack.joinRoom('factory-floor', 'Factory Floor Sync');

// Create and merge CRDTs
const reg1 = createRegister({ temp: 25 }, 'peer-a');
const reg2 = createRegister({ temp: 26 }, 'peer-b');
const merged = mergeRegisters(reg1, reg2); // Last writer wins
